Gantt — Best For Parallel Workstreams
Use dateFormat HH:mm with real incident times — much cleaner than the dateFormat X (Unix ms) workaround. Tasks can be crit (red), done (grey), or default (blue). Use milestone for zero-duration events.

Key syntax:
taskName :crit, id, HH:mm, Xm
taskName :milestone, id, HH:mm, 0m
taskName :after id, Xm — relative to another task
Timeline — Best For Narrative Chronology
The timeline type (Mermaid v9.4+) is ideal for a quick readable summary. Group events by section. Each event can have multiple notes on separate lines. Simple, no duration tracking — purely sequential.

Key syntax:
section Phase Name
HH:mm : Event label : Note
Sequence — Best For Role Handoffs
Use sequenceDiagram to show who talks to whom — escalations, acknowledgments, updates between MIM / TECH / COMMS / Leadership. Supports activation boxes (activate/deactivate) to show when someone "owns" the call.

Key syntax:
MIM->>TECH: Assign investigation
TECH-->>MIM: Root cause confirmed
Note over MIM,COMMS: Bridge active
Flowchart — Best For Decision Trees
Use flowchart TD (top-down) or LR (left-right) for escalation paths, runcard decision trees, or phase transition logic.

Key syntax:
A[Box-3 Alert] --> B{MIM Available?}
B -->|Yes| C[Assume Command]
B -->|No| D[Escalate to On-Call]

```mermaid

```

The app's markdown pipeline recognizes Mermaid fences during build and render time, so diagrams can live beside the product docs without a separate static docs toolchain.
